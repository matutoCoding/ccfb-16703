# 看台视线分析与座位视角预览系统

浏览器端体育场看台视线设计工具。TypeScript + React + three.js + IndexedDB,无需后端,数据全部保存在本地浏览器。

## 启动

```bash
npm install
npm run dev        # 开发服务器,默认 http://127.0.0.1:5180
npm test           # 运行视线算法测试(vitest,14 个用例)
npm run build      # 生产构建
```

首次打开在「方案列表」页可直接载入两个内置测试方案:
- **四万座足球场**:105×68 场地,四边直台 + 四角弧形转角,40 排,39,856 座
- **一万座篮球馆**:28×15 场地,四边直台 + 四角弧形转角,28 排,9,904 座

## 六个页面

| 页面 | 功能 |
| --- | --- |
| 方案列表 | 新建/复制/删除方案;改动自动落库并按时间生成历史版本,可回滚到任意一版 |
| 场地与焦点 | 足球/田径/篮球三类场地;视点焦点按规范自动落在边线或跑道外沿,支持手动改 |
| 看台建模 | 直线/弧形分区,排数、排距、首排高度、等升起/变升起;弧形转角按同心圆弧展开 |
| 视线分析 | 逐排 C 值(不达标红色)、边线遮挡深度、一键反推升高、障碍物遮挡热力图、票价分区建议、CSV/SVG 导出与打印 |
| 座位预览 | 点任意座位切第一人称眼高视角,坐姿/站姿切换,前排观众简模,实时场地遮挡比例 |
| 设置 | 眼高、最小 C、施工取整步长、热力网格、历史上限、票价区管理 |

## 核心算法与硬要求

### C 值(规范剖面公式)

视点 F,前排眼 E₁(水平距离 d₁、标高 Y₁),本排眼 E₂(距离 d₂、标高 Y₂):

```
C = (Y₂ − F) · d₁/d₂ − (Y₁ − F)
```

C ≥ 规范最小 C 值(默认 60mm)即合格。视线经前排眼睛延长至地面,交点伸入场地一侧的距离即边线被遮挡深度。

### 变升起反推(手册逐排递推法)

由 C ≥ Cmin 解出本排眼高下限:

```
Yₙ ≥ F + (dₙ/dₙ₋₁) · (Cmin + Yₙ₋₁ − F)
```

每一排代入**前排实际采用(已取整)标高**求本排眼高,踏步面标高按施工步长(默认 1mm)向上取整,并保证不小于前排标高加一个步长。

该构造**结构性保证**两件事(由 `tests/sightline.test.ts` 锁定):

1. 反推升高代回正向计算,**每排 C 值均不小于设定最小 C**(含 100 组随机参数模糊测试、直线与弧形看台);
2. 每级实际升高与未取整手算公式之差**严格小于一个施工步长(1mm)**,且为非负偏差。

另有独立手算递推对照测试,防止主代码与测试同源出错。

### 障碍物遮挡

- 挑檐、栏杆:轴对齐盒体,线段与盒体 slab 求交
- 立柱:竖直圆柱,二次方程求交并校验高度区间
- 每个座位向场地网格(默认 24×16)逐点投射线,统计被遮挡比例生成热力图

## 目录结构

```
src/
  model/        纯数据与算法(不依赖 three.js,可在 Node 下直接测试)
    types.ts        数据模型
    geometry.ts     直线/弧形看台平面几何
    sightline.ts    C 值、逐排分析、变升起反推
    occlusion.ts    盒体/圆柱遮挡求交、场地遮挡网格
    pricing.ts      视线质量评分与票价分区
    exporter.ts     CSV / SVG 剖面 / 打印报告
    factory.ts      场地预设与工厂
    presets.ts      两个内置测试方案
  db/           IndexedDB 封装(方案表 + 历史版本表)
  three/        three.js 场景构建
  pages/        六个页面
  state/        React 全局状态(自动保存 + 历史版本)
tests/          vitest 算法测试
```

## 数据存储

IndexedDB 库 `stand-sightline-db`,两个对象仓库:`schemes`(方案)、`versions`(历史快照,按 schemeId 索引,超上限自动淘汰最旧版本)。编辑后 600ms 防抖落库,距上次快照超过 30 秒才产生新版本,避免版本爆炸;反推应用等关键操作会立即存快照。
